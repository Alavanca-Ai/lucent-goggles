# Sistema de Agentes

Este documento armazena o contexto sobre os agentes IA utilizados neste projeto e as instruções globais.

## Agentes Ativos
- **Antigravity (Desenvolvedor Web)**: Agente encarregado de implementar a página de vendas (landing page) seguindo as especificações de design (`HERO.MD` e `LUCENT.md`), utilizando HTML, CSS e JS puros de alta performance.

## Instruções do Projeto
- A página deve manter o padrão de design minimalista, arquitetônico e luminoso.
- Prioridade para acessibilidade e contraste.
- Utilizar a técnica de Scroll Scrubbing (vídeo acoplado à rolagem) cobrindo todo o background do site para a experiência cinematográfica ininterrupta.
- **REGRA DE IDIOMA**: Todo o texto utilizado no site e nos arquivos deve estar sempre em Português do Brasil (pt-BR). Nunca coloque outro tipo de texto ou idioma em nosso site.
